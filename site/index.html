Debug your LeetCode solutions, one line at a time.

LCForge is a desktop app for solving LeetCode problems in Java. Run and judge your code on your own machine, then step through whatever fails — every line, every variable — with a real debugger.

A real debugger

Not print statements. LCForge runs your solution under the JVM's own debugger and records every step, so you can scrub back and forth and watch your arrays, maps, lists and trees change.

Judged like LeetCode

Run tries the case you're looking at. Submit runs them all and says Accepted, Wrong Answer or Time Limit Exceeded — with every case's runtime side by side.

One click from LeetCode

The Chrome extension puts a ⚡ on every problem page. Press it and the statement, the examples and the exact method signature land in LCForge, ready to solve.

An ember that lives on progress

The first time you solve a problem, it pays you Sparks to keep your ember fed. It dims while you're away. It never dies.

Yours, and offline

No account, no cloud, no telemetry. Your problems, solutions and history are plain files in one folder on your computer.

How it works

  1. 1

    Install it

    Download LCForge for your computer. Java comes built in — there's nothing else to set up.

  2. 2

    Bring a problem

    Press ⚡ on any LeetCode problem with the extension, or paste a problem in by hand.

  3. 3

    Solve, then step

    Write Java, Run, Submit. When a case fails, step through it and see exactly where it went wrong.

Questions

Is it really free?

Yes. LCForge is free and open source, with no paid tier and nothing to sign up for. The source is on GitHub.

Do I need to install Java?

No. The installers carry their own Java, trimmed to what LCForge uses. Only the bare jar needs a Java 17 or newer already on your machine.

Which languages does it support?

Java, and only Java. The debugger is built on the JVM's own debugging interface, which is what lets it show you every step, so Java is the language it can do properly.

Why does my computer warn me the first time I open it?

Because the builds aren't code-signed — a certificate that costs a yearly fee. Nothing is wrong with the app; the warning just means "this publisher hasn't paid to be recognised". You only have to get past it once:

Windows: on "Windows protected your PC", choose More info, then Run anyway.
macOS: open System Settings → Privacy & Security, scroll down, and choose Open Anyway next to LCForge.

Does it work with Premium problems?

It works with whatever your browser is showing you. The extension reads the problem you're looking at, through the same request LeetCode's own page makes — so if you can see a problem, LCForge can import it, and if you can't, it can't. It never unlocks anything.

Does it need my LeetCode account?

No. LCForge never signs in to anything, and the extension never sends your cookies or account details anywhere — it only hands the problem on the page to the app on your own computer.

Where is my work kept, and how do I remove it?

In one folder: %LOCALAPPDATA%\LCForge on Windows, ~/Library/Application Support/LCForge on a Mac and ~/.local/share/lcforge on Linux. Help → About in the app shows the exact path. Uninstalling leaves your work in place; delete that folder to remove it too.

Is LCForge part of LeetCode?

No. It's an independent project, not affiliated with, endorsed by or connected to LeetCode.
